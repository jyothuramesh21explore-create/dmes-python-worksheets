What is a Variable?

A variable is a named location in the computer’s RAM designed to hold data that can change (vary) during execution.

player_name = "Fatima" # str
level = 5 # int
The Assignment Operator (=)

The = symbol in Python does NOT denote algebraic equality! It means "is assigned the value of". Evaluation always flows from right to left.

level = level + 1 ➔ Takes current level (5), adds 1 (6), stores back into level.
Teacher Think-Aloud Demonstration

"When I write player_name = \"Fatima\", the Python interpreter allocates memory, labels it player_name, recognizes the double quotes as a sequence of characters (String), and stores it. When I assign without quotes like level = 5, it designates an Integer for arithmetic."

Check for Understanding:

If level = 5, and the program executes level = level + 1, what is the new stored value of level?
