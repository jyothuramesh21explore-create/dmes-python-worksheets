STAGE 4: EXPLICIT INSTRUCTION - Teach Time

⏱ 10:00

The input() function ALWAYS gives us a String (text). You cannot do math on text! We must "cast" (convert) it.

Data Type When to use it Python Function Example
String (str) Text, names, raw input str() or input() "Hello" or "5"
Integer (int) Whole numbers for math int() int("5") becomes 5
Float (float) Decimal numbers / Money float() float("5") becomes 5.0
⚠️ THE DOUBLE PARENTHESIS TRAP: When combining int() and input() on the same line, every open parenthesis must have a closing one at the end.

❌ Wrong: age = int(input("How old are you? ") (SyntaxError: unexpected EOF while parsing)
✅ Right: age = int(input("How old are you? "))
