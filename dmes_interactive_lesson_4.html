STAGE 4: EXPLICIT INSTRUCTION - Teach Time

⏱ 10:00

Printing just a variable is not enough. We want our program to speak to the user using full sentences. Let's look at the three main ways to combine Strings (Text) and Variables (Math Data).

Method Python Code Output
1. Commas
(Easiest, adds spaces automatically)		 print("The area is", area) The area is 50
2. Concatenation (+)
(Requires casting back to a string!)		 print("The area is " + str(area)) The area is 50
3. f-strings
(Modern/Advanced, uses curly braces)		 print(f"The area is {area}") The area is 50
⚠️ THE TYPE-ERROR TRAP (Concatenation): If you try to glue a String and an Integer together using the + sign, Python will crash.

❌ print("Score: " + 100) -> TypeError: can only concatenate str (not "int") to str
✅ print("Score: " + str(100)) -> Works perfectly!
