STAGE 4: EXPLICIT INSTRUCTION - Teach Time

⏱ 10:00

Python has special operators that do very specific, powerful things. Review the table below as the teacher explains.

Operator Name What it does Example
** Exponentiation Raises a number to a power. 3 ** 2 is 9 (3²)
// Floor Division Divides and throws away the decimal (rounds down). 10 // 3 is 3
% Modulus Divides, but ONLY gives you the remainder. 10 % 3 is 1 (3 goes into 10 three times, 1 left over)
⚠️ CRITICAL MISCONCEPTION: The % symbol does NOT mean percentage in Python! It is the Modulus operator (the "leftovers" operator). It is incredibly useful for finding even/odd numbers (e.g., x % 2 == 0).

Strict PEMDAS in Python

  1. Parentheses ()
  2. Exponents **
  3. Multiplication, Division, Floor //, Modulus % (Left to Right)
  4. Addition, Subtraction (Left to Right)

STAGE 5: TEACHER MODEL (I Do)

⏱ 5:00

Watch how Python evaluates this complex expression using strict order of operations.

result = 5 + 2 ** 3 % 4

Tracing the computer's logic...

Step 1 (Exponents): 2 ** 3 becomes 8.
Expression is now: 5 + 8 % 4
Step 2 (Modulus): 8 % 4 becomes 0 (4 goes into 8 evenly).
Expression is now: 5 + 0
Step 3 (Addition): result = 5
