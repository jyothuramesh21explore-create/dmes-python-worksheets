Teach Time: The input() Function

To make programs dynamic (interactive), we must capture user input. In Python, we use the input() function.

Syntax Breakdown

user_name = input("What is your name? ")
  • user_name: The variable where we save the answer.
  • input(): The built-in Python command to pause and wait for the keyboard.
  • "What is your name? ": The prompt displayed on the screen so the user knows what to type.

The Golden Rule

The input() function ALWAYS returns a STRING.

Even if the user types 15, Python sees it as "15" (text, not math).

Stage 5: Teacher Model (I Do)
⏱ 5:00

The Digital Bouncer

Watch as the teacher builds a program that asks for an age and tries to do math on it.

1. The Broken Code

print("Welcome to the club.") age = input("Age: ") # Attempting to add 5 years to the age future_age = age + 5 print("In 5 years you will be: " + future_age)

2. The Fix (Type Casting)

print("Welcome to the club.") # Wrap input() inside int() to convert to Number age = int(input("Age: ")) future_age = age + 5 # Convert back to str() to print with text print("In 5 years you will be: " + str(future_age))
